# World Interiors Plan

> **Owner:** A08 — Architect. **Status:** plan + validated data, no geometry generated in this pass.
> **Data:** `Content/Data/World/interiors.json`, `portals.json`, `anchors.json`, `spawns.json`.
> **Constraint:** do not hand-edit the `.umap`; interiors are generated by `Tools/` and placed by the editor build.

## 1. Decision: portal cells vs in-place

| Approach | Used for | Why |
|---|---|---|
| **In-place** | Academy lobby, Grand Duel Arena, Card Shop, Slifer cafeteria/dining annex, Ra cafeteria, Duel Gym hall, Abandoned Dorm entrance hall | These interiors already exist in the procedural meshes and are walk-in. Adding geometry would mean rebuilding large exterior shells for no visual gain. |
| **Portal cell** | Academy classroom, exam room, Crowler office, Chancellor office; Slifer player/Banner/Jaden rooms; Ra player room; Obelisk dining/player room | The exterior blocks are solid shells. A portal cell gives a controlled, story-sized room without touching the exterior kit, and keeps the level regeneration deterministic. |
| **Merged** | Slifer/Ra/Obelisk common rooms, arena backstage, harbor office, ocean shoreline | The existing room or zone already serves the beat; a second room would be empty most of the year. |

**Cell placement:** all cells are in a dedicated block centred at UE `(300000, 300000, -30000)` cm, 2,000–2,500 cm apart on a grid. That is below the sea floor and above the level kill plane (`-50000`), so no terrain, ocean or sky light leaks in. Cells are ordinary level geometry: no streaming, no loading screen, no persistent tick. The camera fades for 0.35 s and the portal teleports when the screen reaches black; the return portal is suppressed until the player leaves its trigger.

**Fade/lock contract:** 0.35 s out, 0.35 s in, 1.5 s cooldown, `StartCameraFade` (no UMG/loading screen). ## 4. Lighting / collision / nav requirements

### Lighting
- Each cell gets **4–6 static/movable point lights** (warm ceiling lamps, one cool window fill). No directional sun inside the cell block.
- Emissive materials only for signs, tank glow, stage edge and card-shop displays; do not rely on emissive for room illumination.
- Max 1 shadow-casting light per cell; the rest are unshadowed fill. This keeps the interior block cheap while the exterior sun is still active.
- The block is below the landscape; verify no sky-light bleed at the cell seams. If a seam leaks, add a ceiling/roof slab (the room shell already closes it).

### Collision
- Floor and walls: complex collision from the generated mesh (`SM_Interior_*`), never `none`.
- Props: simple/complex collision; desks, beds and counters must block the player but not create nav islands in the door path.
- Portal triggers: `UBoxComponent`, `QueryOnly`, pawn overlap only, no nav affect. Trigger depth 60–120 cm; do not overlap the arrival point.
- Door leaves are decorative; the portal trigger is authoritative. No physics doors in this pass.

### Nav
- One `NavMeshBoundsVolume` covering the whole interior block (or one per cell). Rebuild nav after generation.
- Keep a 1.2 m clear path from the exit trigger to the room centre; no desk/bed within 80 cm of the door.
- NPC spawn points use `SpawnZOffset = 90 cm` (capsule half-height) so `ADANpcSpawnPoint` actors sit on the floor.
- Run a nav reachability check per cell: exit trigger → every spawn anchor → exit trigger. A cell with no reachable path fails the interior test.

### Performance budget

| Budget | Target | Notes |
|---|---|---|
| Interior transition | < 2 s | Target 0.7 s: 0.35 s fade out + teleport + 0.35 s fade in. No level load. |
| Per-cell draw calls | ≤ 12 | Merge trim/props by material; reuse the kit. |
| Per-cell lights | ≤ 6 | 1 shadow caster max. |
| Per-cell triangles | ≤ 15k | Kit rooms, not hero archviz. |
| Permanent tick cost | 0 | Portals/spawn points/anchors are event-driven; director applies schedules only. |
| Memory | < 50 MB for 10 cells | Shared materials/meshes; no unique textures per room. |

## 6. Generation steps (next pass)

1. **Create `Tools/dai/assets/interiors.py`** (owned by A08). One `AssetSet` per cell, built in local metres at the cell origin; reuse `MeshBuilder.room`, `box`, `cylinder`, `wall` and the existing material palette.
2. **Export meshes** into `SourceAssets/Meshes/Locations/Interiors/<cell>/SM_<cell>_*.fbx` with complex collision; keep `_NoCol` for glow/signs.
3. **Add `Layout.place_interiors()`** to `Tools/dai/layout.py`. It reads `Content/Data/World/interiors.json`, exports each cell at its `origin_ue`, appends `static`, `lights`, `texts`, `interacts` and `specials` entries, and does **not** touch the existing building placements.
4. **Extend `Layout.write()`** with a `world_actors` block for portals/anchors/spawns (or have `level.py` read the JSON directly). Do not hand-place actors in the `.umap`.
5. **Extend `DuelAcademyIsland/Content/Python/duel_academy/level.py`** to spawn `ADAInteriorPortal`, `ADASceneAnchor`, `ADANpcSpawnPoint` and one `ADANpcDirector` from that data. Tag every actor with `C.GENERATED_TAG`.
6. **Add a nav volume** in `level.py` for the interior block (`NavMeshBoundsVolume`), then rebuild navigation.
7. **Add interior light rigs** in `interiors.py` (point lights only; no new textures). Verify the cell block does not receive sky light.
8. **Regenerate** with `python Tools/build_island.py layout` then run the editor build (`DuelAcademyIsland/Content/Python/duel_academy/build.py`); the island exterior must be byte-identical apart from the new `static`/`world_actors` entries.
9. **Run** `python Tools/world/validate_layout.py --strict` and the in-editor world tests (portal enter/exit, nav reachability, camera anchors).
10. **Only then** add the remaining Academy offices/test room, Ra/Obelisk rooms and polish. Keep the Slifer/gym slice green first.

## 7. Blockers / risks

| Blocker | Impact | Mitigation / owner |
|---|---|---|
| No interior generator module yet | Cells are data only | Add `Tools/dai/assets/interiors.py` + `Layout.place_interiors()` (A08, next pass). |
| Portal/anchor/spawn actors are not spawned by `level.py` | Data is not instantiated in PIE | Extend `level.py` with the new actor classes; no `.umap` edits (A08/A10). |
| A02 flag query not bound | Story/dorm door locks fail open | `ADAInteriorPortal::FlagQuery` hook; bind in profile/game mode; keep `fail_closed:false` until then. |
| Named NPC cast overrides | Spawns use generic `ADAStudentNPC` | Add cast/portrait mapping in A08 data; A09 portrait layer already owns appearance. |
| Ra/Obelisk room doors are facade bays | Portal sits on a window, not a door | Generator adds door leaves/steps, or a temporary marker mesh. |
| Chancellor office reads as ground floor | Minor fiction mismatch | Add a stair/elevator transition in a later pass; the room/door data stays valid. |
| Interior lighting/nav performance unmeasured | Could miss 60 fps | Point-light cap, 1 shadow caster, nav test, profile after first cell. |
| Gym is a Duel Gym, not a school gym | Visual mismatch with GBA | Accept for the vertical slice; add a school-gym dressing pass later if needed. |
