# Legal and asset audit — Duel Academy Island

**Status:** engineering audit completed 2026-10-31. This is not legal advice; a
publisher/distribution review is still required before any public release.

## 1. Repository hygiene

| Check | Result |
| --- | --- |
| ROM / save / emulator binaries tracked | **none** (`git ls-files` scan for `.gba`, `.sav`, `.sgm`, `.state`, `.iso`) |
| Card art under `Content/Data/CardArt/` | **untracked / local-only** |
| Character portraits under `Content/Data/Portraits/` | **untracked / local-only** |
| Combined anime meshes under `SourceAssets/Meshes/Characters/Anime/Combined/` | **untracked / local-only** |
| Absolute workstation paths in tracked data/docs | **sanitized**; extraction tools read `$GX_ROM` / `$GX_CANON_LOCAL_DIR` |
| Canon extraction cache | **ignored** (`Tools/canon/cache/`) |

The packaging output is written to `Builds/` and is ignored by Git. No packaged
build is committed.

## 2. Source assets

- Island terrain, buildings, interiors, props, avatar parts, VFX and UI are
  generated by the procedural pipeline in `Tools/` or built in this repository.
- The animated student (`SK_Student`) is derived from the CC0 Quaternius worker;
  the anime cast is derived from VRoid sample avatars under their embedded
  conditions of use. See `CREDITS.md`.
- Third-party meshes/textures/HDRIs are CC0, CC-BY 3.0/4.0, MIT (EZ-Tree) or
  VRoid terms. Attribution is collected in `CREDITS.md`; every source folder has
  a `SOURCE.txt` and license evidence under `Tools/thirdparty/license_evidence/`.
- The packaged build includes Epic's `NOTICES.txt`. `CREDITS.md` must also be
  copied into a public distribution; it is not currently staged automatically.

## 3. Duel data and card assets

- `Content/Data/cards.json` and the canon extracts contain card names and rules
  text ported from the GBA reference for this non-commercial fan project.
  Yu-Gi-Oh! names/text/artwork belong to Konami/Shueisha.
- Card scans and character busts are **not committed** and are not part of the
  clean-clone build. A release that includes them needs explicit permission.
- The 1,200-card runtime data, canon manifests, decks and effect scripts are
  derived data. They are retained for preservation/interoperability and must be
  reviewed before any commercial distribution.
- The ROM itself is never copied into the repository; extraction tools require
  the user to set `GX_ROM`.

## 4. Code and engine

- Gameplay code, tools, docs and generated data are original work for this
  project, except for Unreal Engine code and third-party libraries covered by
  their own licenses.
- Unreal Engine 5.8 use is governed by the Epic Games EULA. The packaged build
  carries `NOTICES.txt`; review it before distribution.
- No emulator, ROM patcher, BIOS or copyrighted firmware is included.

## 5. Distribution checklist

- [ ] Legal review of card names/text and any optional local-only card art.
- [ ] Include `CREDITS.md`, `NOTICES.txt` and third-party attribution in the
      installer/archive.
- [ ] Confirm the build does not package `Content/Data/CardArt/`,
      `Content/Data/Portraits/` or `SourceAssets/.../Anime/Combined/`.
- [ ] Add a fan-project disclaimer to the title/credits screen.
- [ ] Re-run the repository scan after packaging and before tagging.
